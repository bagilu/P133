# P133 資料狀態與教學邊界（V0.005）

## 本版資料性質

| 項目 | V0.005 狀態 |
|---|---|
| 地圖輪廓 | 手工簡化的教學示意幾何 |
| 面積欄位 | 用於介面原型的近似公認統計值；正式版需逐筆鎖定定義、來源、年份與版本 |
| 國界／行政界爭議 | 尚未處理；不得據此作主權、行政、法律或測量判斷 |
| 資料庫 | 已設計為可儲存來源、授權、版本與比較口徑 |

## 正式資料導入原則

1. 每筆 Geometry 都需有 `GeometrySource`、`GeometryLicense`、`GeometryVersion` 與取得日期。
2. 每筆面積需有資料年份、採用口徑與來源；陸地面積、總面積與領海面積不得混用。
3. 爭議疆界或不同統計口徑，使用獨立 `ComparisonVariant`，不以覆蓋既有資料處理。
4. 導入前應確認來源可公開展示與再散布的授權條件。
5. 前端只取得呈現與比較必要欄位；原始資料與管理註記不得不必要公開。
